# Apollo 🎵🐧

> 🏷️ **更名说明**：本软件自 **v1.42.2** 起显示名改为 **Apollo**。包名、签名与本地数据均不变，覆盖安装即可无缝升级。

一款把 B 站当音乐库用的安卓播放器：用你自己的 Bilibili 账号登录，搜索并播放视频的音频，
把 B 站收藏夹当歌单，支持后台播放、旋转黑胶唱片与滚动歌词。

> 由 **清木** 与 AI 助手「小咕嘎」共同打造的个人项目。非官方应用，与哔哩哔哩、网易云音乐均无隶属关系。

> 🎖 **军师**：MC风月无边（[GitHub](https://github.com/MCfywb)，B 站 [space.bilibili.com/432245733](https://space.bilibili.com/432245733)）——音质五档、歌词多源、双更新源等关键建议均出自军师，特此鸣谢！

## ✨ 功能

- 🔐 **账号登录**：内嵌 B 站官方登录页完成登录，凭证只保存在手机本地，不经过任何第三方服务器
- 🔍 **搜索与播放**：WBI 签名接口搜索/取流（算法实现见 `test/Wbi.java` 的官方测试向量验证）
- ⭐ **收藏夹当歌单**：读取你的 B 站收藏夹（含自动翻页），点开即播
- ▶️ **后台播放**：前台服务 + 通知栏控制（上一首/暂停/下一首），支持顺序/单曲循环/随机
- 🫧 **悬浮岛**：仿原子岛的顶部悬浮胶囊——平时小胶囊显示封面与歌名，点开动画展开播放/暂停、下一首，几秒后自动收回；设置「播放」区开启（需悬浮窗权限）
- 🎤 **状态栏歌词**：切出 App 后在屏幕顶部逐行显示当前歌词，带二级设置（位置/宽度/背景透明度/字号/颜色，颜色可跟随封面），设置「播放」区进入（需悬浮窗权限）
- 💿 **旋转黑胶唱片**：播放页圆形封面唱片，播放转、暂停停
- 🎤 **歌词显示**：六源级联匹配——QQ音乐 / 网易云 / 酷狗 / AMLL TTML / LRCLIB 按歌名+歌手+时长打分防错配，顺序可在「设置」里自定义，全部落空时用视频自带字幕兜底；歌词本地缓存，播放页五线窗口 + 全屏歌词页（点行跳转）
- 🎨 **8 套主题**：哔哩粉（默认）/ 天空蓝 / 薄荷绿 / 紫电葡萄 / 极光穹顶 / 抹茶玄米 / 彩虹桥 / Material You（扁平无光晕），全套共享磨砂玻璃质感（玻璃卡片 + 双色光晕渐变）
- 📊 **播放统计**：日/周/月/年/总五档（播放次数 / 累计时长 / 曲目数）+ 最常播放榜，数据只存本地、400 天封顶
- 🔍 **搜索分页**：每页 50 条，下拉自动续接下一页
- 📳 **3D 触感**：按键与点选带系统级振动反馈（可在设置里关）
- 🛡️ **播放自愈**：CDN 节点失败自动换址重取、加载卡死巡检、音频焦点冲突防护（vivo 等机型通知栏暂停后无法恢复的问题已定位修复）
- 🩺 **播放诊断**：设置页内置诊断日志，播放异常时可截图定位
- 🕘 本地播放历史
- 🔄 **在线更新**：打开 App 自动检查新版（可在设置里选 GitHub/Gitee 首选源，检查与下载失败自动换源）；点更新后在卡片内前台下载带进度，校验安装包大小与包名/版本无误后**自动拉起安装**，未授权「安装未知应用」时跳设置授权、回来自动续装

## 📦 安装

到本仓库的 **Releases** 下载最新 APK 直接安装（安卓 8.0+）。覆盖安装不丢数据；请勿卸载重装（本地数据会清空）。

## 🔨 构建

本项目没有用 Gradle（开发机上 Gradle 守护进程无法启动），使用 Android 构建工具手动管线打包，
且**不依赖任何第三方库**——纯 Android 框架（Java）实现。

准备：JDK 17 + Android SDK（platform 34 / build-tools 34.0.0），然后：

```bash
export JAVA_HOME=/path/to/jdk17
export ANDROID_SDK=/path/to/android-sdk
./build.sh 12 1.9.0   # 参数：versionCode versionName
```

## 🧩 技术要点

- Bilibili 接口：`x/web-interface/nav` 取 WBI 密钥 + `spi` 取 buvid，请求走 WBI 签名；播放取 `wbi/playurl` 的 DASH 音频流（优先 AAC），失败时按「备用地址 → 刷新签名重取 → 跳歌」自愈链处理
- 网易云歌词：`cloudsearch/pc` 检索（标题清洗 + 时长比对防配错版本）→ `api/song/lyric` 取 LRC
- QQ音乐歌词：`search_for_qq_cp` 检索 → `fcg_query_lyric_new` 取 LRC；AMLL TTML：按 QQ songmid / 网易云歌曲 ID 查 amll-ttml-db（jsdelivr 镜像优先），TTML 逐字轴转行级 LRC
- 字幕兜底：`x/player/v2` 字幕轨转同步文本
- 数据存储：登录凭证与歌词缓存都在应用私有目录；历史记录用 SQLite

功能清单与迭代记录见 `FEATURES.md` 与应用内「设置 → 播放诊断」。
